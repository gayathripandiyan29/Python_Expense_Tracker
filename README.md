
# Expense Tracker

A Python-based Expense Tracker application that helps users manage and analyze their daily expenses.

## Features

- Add Expenses
- View All Expenses
- Update Expenses
- Delete Expenses
- Search Expenses
- Last 15 Days Expense Analysis
- Total Expense Calculation
- Expense Dashboard with Charts
- Generate PDF Expense Report
- Top Spending Category
- Recent Transactions
- Monthly Budget Alert
- Monthly Summary
- Open Excel to View Saved Data

## Technologies Used

- Python
- Pandas
- Matplotlib
- Excel
- ReportLab

## Project Files

- `main.py` – Main application code
- `expenses.xlsx` – Stores expense records
- `Expense Chart` – Expense chart output
- `Expense Report` – Expense report output

## How to Run

1. Install Python.
2. Install the required libraries.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```
